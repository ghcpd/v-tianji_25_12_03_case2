## 3) Breaking Changes Assessment

### React 16 → 19
- **ReactDOM.render** → `createRoot`
- **UNSAFE lifecycles** may break under concurrent rendering
- StrictMode double-invokes effects in dev

**Affected files**: index.js, App.js, Dashboard.js, Products.js, Analytics.js

### React Router v5 → v6/7
- `Switch` → `Routes`, `Route element={<Component />}`
- `withRouter` removed → `useLocation`, `useNavigate`
- `Redirect` → `Navigate`

**Affected**: App.js, Navigation.js (links ok), tests

### Webpack 4 → 5
- `devServer.contentBase` → `devServer.static`
- Node polyfills removed; update loaders
- Built-in `asset` modules; update `terser-webpack-plugin`
- Requires `webpack-cli@5/6`, `sass-loader@>=12`

**Affected**: webpack.config.js, loaders, package.json

### Babel
- `corejs:2` → `corejs:3`
- Update presets/plugins and polyfill imports

### Jest 24 → 30
- Install `jest-environment-jsdom`
- `transform` stays; ensure `babel-jest` 30
- Add `src/setupTests.js` (import `@testing-library/jest-dom`)

## 5) Migration Strategy (Step-by-Step)

1. **Tooling foundation**
   - Replace `node-sass` → `sass`
   - Upgrade webpack/cli/dev-server, loaders, core-js, Babel
   - Update .babelrc to `corejs:3`
   - Update webpack.config.js (`static`, `output.clean`, `target: 'web'`)
2. **React & ReactDOM**
   - Upgrade to React 19
   - `ReactDOM.createRoot` in index.js
3. **React Router**
   - Upgrade to v7
   - Refactor App.js to functional + `Routes`
4. **Components & Redux**
   - Convert class components to functional hooks (`useState`, `useEffect`, `useSelector`, `useDispatch`)
   - Optionally adopt Redux Toolkit (future)
5. **Testing**
   - Upgrade jest/babel-jest, add `jest-environment-jsdom`
   - Add `src/setupTests.js` with `@testing-library/jest-dom`
6. **Linting & ESLint**
   - Upgrade eslint + plugins, fix rules
7. **Validation**
   - Run `npm test`, `npm run build`, `npm audit --production`
   - Add CI audit step

**Order rationale**: Tooling → React → Router → Components → Tests → Lint.
