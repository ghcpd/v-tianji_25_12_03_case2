## 🧭 Breaking changes assessment (major upgrades & affected files)

1) React 16 → 18 (or 19)
   - Breaking items: legacy lifecycles (componentWillMount/ReceiveProps/Update), stricter StrictMode behavior, root API change (ReactDOM.render → createRoot).
   - Affected files found and changed: index.js (mount), App.js, `src/components/*` (Dashboard, Products, Analytics)
   - Migration notes: convert class components to hooks or update lifecycles; for server-side effects inspect async behavior; migrate to createRoot in entrypoint.

2) React Router v5 → v6/7
   - Breaking items: `Switch` replaced by `Routes`, `component` prop removed in favor of `element={<Comp />}`, `withRouter` removed in favor of hooks (useLocation, useNavigate, useParams).
   - Affected files: App.js (used Switch and withRouter). Other route-aware components may need changes.

3) Webpack 4 → 5
   - Breaking items: devServer `contentBase` → `static.directory`, asset modules (file-loader/url-loader behaviour), updated plugin hooks (html-webpack-plugin v4→v5).
   - Affected files: webpack.config.js, plugin/loaders versions defined in package.json.
   - Migration notes: update loader options, ensure compatibility with webpack 5.

4) core-js v2 → v3
   - Breaking items: import path and polyfill usage changed; babel's preset-env must be given corejs: 3.
   - Affected files: index.js (polyfill imports), Babel config (if present).

5) node-sass → sass
   - Breaking items: node-sass is deprecated; use `sass` (Dart Sass) with updated `sass-loader` version and config.
   - Affected files: package.json, webpack.config.js / loaders.
