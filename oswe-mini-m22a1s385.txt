## Breaking Changes Assessment — major upgrades & affected files 🔧

1) React 16 → 18
- Breaking: `ReactDOM.render` -> `createRoot`; concurrent rendering semantics; some deprecated lifecycle methods.
- Files impacted: index.js, components using UNSAFE lifecycle methods: App.js, `src/components/*`.
- Migration: replace UNSAFE_* methods with `componentDidMount`, `componentDidUpdate` or convert to hooks. (I changed several files as examples.)

2) react-router v5 → v6
- Breaking: `Switch` -> `Routes`, `component` prop removed, route components passed via `element={<Component/>}`, `withRouter` removed; `useNavigate`, `useLocation`.
- Files impacted: App.js, any components using `withRouter`.
- Migration examples provided in App.js.

3) core-js v2 -> v3 + Babel config
- Breaking: `core-js` import semantics largely same, but Babel config must set useBuiltIns: 'entry' and corejs: 3
- Files impacted: webpack config / babel loader options and index.js if you use `core-js/stable` and `regenerator-runtime/runtime`.
- Migration: update @babel/preset-env to `corejs: 3`.

4) node-sass -> sass + sass-loader
- node-sass is deprecated and may be removed from platform; switch to `sass` and update `sass-loader` to a modern version compatible with webpack 5.
- Files impacted: webpack config and package.json

5) Webpack 4 -> 5
- Breaking: devServer `contentBase` → `static.directory`; asset modules replace file-loader/url-loader in some cases.
- Files impacted: webpack.config.js
- Migration: update devServer config, ensure loaders compatibility.

6) ESLint, Babel, Jest upgrades
- May show new lint/test failures; adjust configs.
