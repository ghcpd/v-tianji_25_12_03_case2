# Collaboration Test Application

A complex frontend application designed to test collaboration scenarios, particularly focusing on inconsistent labeling policies across the codebase.

## Technology Stack

- React 18
- TypeScript
- Vite
- React Router
- Zustand (State Management)
- Axios (HTTP Client)
- SCSS/CSS Modules

## Project Structure

```
src/
├── components/          # React components with inconsistent naming
├── pages/              # Page components
├── services/           # API services with different patterns
├── store/              # State management (Zustand)
├── context/            # React Context
├── utils/              # Utility functions
└── App.tsx             # Main application component
```

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build
